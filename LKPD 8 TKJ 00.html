2 Ringkasan Teori: Konfigurasi Access Point & 6 Mode Operasi

Wireless Networking Standard

Access Point (AP) adalah perangkat keras jaringan nirkabel yang memancarkan sinyal gelombang frekuensi radio (RF) untuk menghubungkan perangkat klien (laptop, smartphone, tablet) ke jaringan lokal (LAN) berbasis kabel. Selain berfungsi sebagai pemancar standar, Access Point memiliki 6 mode operasi sesuai kebutuhan topologi.

Tabel 6 Mode Operasi Wireless Utama

Mode Operasi Alur Kerja Data Fungsi Utama / Topologi Fitur DHCP Server
AP Mode (Access Point) Meneruskan data dari port LAN kabel ke pemancar nirkabel secara transparent (Bridge Layer 2). Menambahkan cakupan Wi-Fi pada jaringan kabel yang sudah ada. Disabled (Mengikut Router Utama)
Wireless Router Mode Menerima sinyal WAN dari modem/ISP pada port WAN, lalu membagikannya via Wi-Fi/LAN menggunakan NAT. Sebagai gateway utama rumah/kantor kecil untuk berbagi koneksi internet ISP. Enabled (Membagikan IP Private)
Repeater / Extender Mode Menangkap sinyal Wi-Fi dari AP Utama lalu memancarkan kembali sinyal tersebut. Perluasan jangkauan sinyal (coverage extension) tanpa menarik kabel LAN tambahan. Disabled (IP dialokasikan AP Utama)
Wireless Client Station Mode Berfungsi seperti Wi-Fi Card/Adapter nirkabel. Menangkap sinyal Wi-Fi dan meneruskannya ke port LAN fisik. Menghubungkan perangkat wired (Smart TV, PC, DVR CCTV) ke jaringan nirkabel. Disabled
WISP Mode (Wireless ISP) Menangkap sinyal Wi-Fi luar (Hotspot/ISP) sebagai sumber WAN, lalu membuat sub-jaringan baru via NAT. Menghubungkan jaringan lokal rumah ke pemancar Wi-Fi berlangganan luar tanpa kabel. Enabled (Membuat Subnet Separate)
Bridge Mode (PtP / PtMP) Menghubungkan dua atau lebih segmen jaringan LAN kabel secara nirkabel (Point-to-Point). Koneksi nirkabel antargedung (misal: Gedung A ke Gedung B) yang terpisah jarak fisik. Disabled

SSID & Security Protocol

SSID: Identitas/nama jaringan nirkabel. Security: Enkripsi WPA2/WPA3-Personal (AES) untuk mengamankan komunikasi data dari pembajakan.

Channel & Bandwidth (Width)

Pemilihan frekuensi (Kanal 1, 6, 11 pada 2.4 GHz) dan lebar pita (20 MHz / 40 MHz) untuk memaksimalkan throughput serta mencegah interferensi.

Tx Power & MAC Filtering

Tx Power: Daya pancar radio (dBm/mW). MAC Filtering: Kontrol akses berbasis alamat fisik (Allowlist / Denylist) untuk mencegah penyusup.
