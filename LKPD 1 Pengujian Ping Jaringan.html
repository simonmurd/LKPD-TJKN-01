Bagian 1: Identitas Peserta Didik

Harap lengkapi Identitas Peserta Didik terlebih dahulu untuk membuka Bagian 2 s/d Bagian 6.

Bagian 2: Tujuan Pembelajaran, Alat & Bahan

Tujuan Pembelajaran
  • Memahami fungsi perintah ping untuk troubleshooting jaringan.
  • Menggunakan aplikasi network tools di Android (Termux/Ping IP).
  • Menganalisis status konektivitas & latensi jaringan secara akurat.
Alat & Bahan
  • Smartphone Android terhubung ke Wi-Fi / Seluler.
  • Aplikasi Android (Termux / Ping IP / Network Analyzer).
  • Target IP Gateway, DNS Google, atau Website publik.

Bagian 6: Soal Evaluasi Pilihan Ganda (20 Soal)

1. Apakah fungsi utama dari perintah ping dalam suatu jaringan komputer?

2. Protokol lapisan jaringan manakah yang digunakan secara langsung oleh utilitas ping untuk mengirim pesan?

3. Apa arti dari status pesan "Request Timed Out" (RTO) saat Anda menjalankan pengujian ping?

4. Perilaku default perintah `ping 8.8.8.8` pada aplikasi terminal Android berbasis Linux (seperti Termux) adalah...

5. Satuan standar yang digunakan untuk mengukur nilai waktu tunda (latency) pada pengujian ping adalah...

6. Pada baris respons balasan ping, terdapat istilah TTL. Apakah kepanjangan dari TTL?

7. Apakah fungsi utama dari adanya nilai TTL pada paket IP yang dikirimkan dalam jaringan?

8. Jika Smartphone berhasil ping ke IP Gateway (192.168.1.1) tetapi gagal (RTO) saat ping ke IP publik Google (8.8.8.8), letak gangguan terbesar berada di...

9. Manakah di bawah ini yang menjadi penyebab utama melonjaknya nilai latency (ping tinggi) saat melakukan pengujian via koneksi Wi-Fi?

10. Pesan kesalahan "Destination Host Unreachable" pada hasil perintah ping menandakan bahwa...

11. Manakah aplikasi emulator terminal populer di Android yang mendukung eksekusi perintah ping berbasis teks/CLI?

12. Berapakah ukuran muatan data (payload) bawaan standar yang dikirim oleh perintah ping pada Linux/Android?

13. Perintah yang tepat pada Termux untuk membatasi eksekusi pengujian ping hanya sebanyak 5 kali pengiriman paket adalah...

14. Alamat IP khusus yang berfungsi sebagai Loopback Address untuk menguji tumpukan TCP/IP internal pada perangkat Anda sendiri adalah...

15. Alamat IP DNS Publik milik Google yang paling sering dijadikan target acuan tes koneksi internet global adalah...

16. Apakah peran utama dari layanan Domain Name System (DNS) saat Anda melakukan ping ke alamat `www.google.com`?

17. Jika pengujian ping ke IP Loopback `127.0.0.1` menghasilkan status Request Timed Out, maka diagnosa awal yang paling tepat adalah...

18. Apa arti dari informasi statistik "0% packet loss" pada rangkuman akhir setelah perintah ping selesai dijalankan?

19. Mengapa utilitas pengujian ping tidak menggunakan nomor port tertentu seperti halnya protokol HTTP (Port 80) atau SSH (Port 22)?

20. Menurut alur baku troubleshooting jaringan, langkah awal pengujian ping yang paling tepat saat memeriksa masalah internet adalah...
