Perintah Ping & IP Dasar

Perintah ping menggunakan protokol ICMP untuk menguji konektivitas jaringan. Default payload Linux/Android adalah 64 byte (56 byte ICMP payload + 8 byte header). Loopback address 127.0.0.1 digunakan untuk menguji tumpukan TCP/IP internal perangkat.

Media Transmisi & Pengkabelan

Standar pengkabelan T568B menempatkan Putih-Oren dan Oren pada pin 1-2. Batas jarak maksimum UTP Cat6 tanpa repeater adalah 100 meter. Serat optik single-mode menggunakan core sangat kecil (~9 mikron) untuk jarak jauh tanpa terganggu EMI.
